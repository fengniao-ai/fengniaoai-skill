# 图片翻译接口

## 公开契约

- 接口：`POST /api/v1/img/translate-save`，单张同步处理并保存历史记录。
- 图片支持 JPEG/JPG、PNG、WEBP；不超过 5 MB；公开文档要求最长边不超过 3000 像素。
- `image` 支持 HTTPS 图片链接、base64 data URL 或由 CLI 读取的本地图片。请求超时建议至少 120 秒。
- 必填：`request_id`、`image`、`lang_from`、`lang_to`、`engine`。
- `engine`：`1` 基础版、`2` 高精版、`3` AI 语义版。Skill 优先使用 `3`；自动识别或仅高精版支持的语言组合自动使用 `2`。
- `commodity_protection=true` 时保护商品文字，不翻译商品文字。
- `filename` 可选；传入后，后续精修编辑器下载时可恢复原始文件名。CLI 会从 URL 或本地路径自动推断，也允许显式覆盖。
- 服务端实现仍接受 `glossary_enabled` 和 `brand_protect`；仅在项目已配置对应能力且用户明确要求时开启。

成功响应中的 `taskId` 和 `imgId` 分别映射为统一结果的 `task_id` 和 `data.image_id`，用于后续接入图片翻译精修编辑器。结果图为 `result.translatedUrl`；擦除文字底图为 `result.processedUrl`；`result.url` 是原图引用，不作为最终交付下载。

该接口不提供旧 `/api/v1/img/translate` 的 `return_text` 或 `return_raw` 输出。用户需要原文、译文和文字坐标时，另行使用 `image ocr`，不要把这两个字段发送给保存历史记录接口。

## 最简参数决策

| 用户选择 | API 参数 |
| --- | --- |
| 已知源语言，语义版支持 | `engine=3`，使用用户确认的 `lang_from` 和 `lang_to` |
| 已知源语言，仅高精版支持 | `engine=2`，使用用户确认的 `lang_from` 和 `lang_to` |
| 源语言不确定 | `engine=2`、`lang_from=auto` |
| 商品名称和包装文字一起翻译（默认） | `commodity_protection=false` |
| 商品名称或包装文字不要翻译 | `commodity_protection=true` |

普通用户不需要选择引擎。Agent 只询问源语言到目标语言，以及商品文字是否翻译；用户未回答商品文字时按“一起翻译”执行。默认不返回原文、译文区域或原始 OCR 数据。

### 自动识别与高精版

- `lang_from=auto` 仅与引擎 `2` 组合。
- 高精版目标语言支持上述大部分语言，并额外支持菲律宾语 `fil`；不支持丹麦语 `da`、希腊语 `el`、匈牙利语 `hu`、印地语 `hi` 作为目标语言。
- 已知语言时优先选择 AI 语义版；菲律宾语等仅高精版支持的组合由 CLI 自动切换，不向用户展示引擎选择。
- 图片翻译使用 `zh`、`en` 等短代码；不要拿视频翻译的 `zh-CN`、`en-US` 区域代码代替。

## 已发现的文档与实现差异

- 新接入文档写最长边不超过 3000 像素，当前服务端实现实际拒绝阈值为 4000 像素。公开 Skill 按更保守的 3000 像素说明，不承诺 3000–4000 像素输入。
- 新接入文档未列出 `glossary_enabled` 和 `brand_protect`，但当前服务端实现会继续传递这两个字段。
- 接入文档的语言附录为空；本表以当前图片翻译产品运行时常量为准，后续产品语言范围变化时应同步更新 Skill 和 CLI 白名单。
